# PSP - Proyecto ferroviario

**Radoslav Radoslavov Atanasov** - 2 DAM semipresencial - Programacion de Servicios y Procesos - curso 2026/27.

Este repositorio contiene las dos primeras entregas del proyecto ferroviario, desarrolladas a partir del codigo base docente de Enrique Niclos Camarasa (IES Lluis Simarro).

| Entrega | Proyecto Eclipse |
| --- | --- |
| v1.1 - Compra de un billete y pago simulado | [TREN_v11_RadoslavRadoslavovAtanasov](TREN_v11_RadoslavRadoslavovAtanasov/) |
| v2.1 - Compra con hilos y reserva atomica | [TREN_v21_RadoslavRadoslavovAtanasov_Threads](TREN_v21_RadoslavRadoslavovAtanasov_Threads/) |

Cada carpeta es un proyecto Eclipse independiente e incluye sus instrucciones. Aplicaciones de consola para **JDK 17 o superior**, sin dependencias externas. Se han usado los nombres de paquete solicitados en las tareas de entrega de Aules.

## Verificacion

- v1.1: 19 comprobaciones de compra, pago, validacion y cancelacion correctas.
- v2.1: 10 escenarios de compra y 4 comprobaciones aisladas correctas; 6.400 intentos concurrentes de reserva con un ganador por ronda y pagos simultaneos.
- Los ZIP finales se han descomprimido, comparado con estas fuentes, compilado y ejecutado correctamente.
